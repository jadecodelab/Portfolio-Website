I built a Todo List application as part of The Odin Project’s JavaScript curriculum. Users can organize tasks into projects, set priorities and due dates, edit task details, mark tasks complete, and delete them.

This project helped me practice separating application logic from DOM manipulation, organizing code with ES modules, bundling with Webpack, and persisting data with localStorage.

Object and state design was one of the most challenging parts. I had to decide how projects and todos should be structured, and how to track the active project.

I plan to revisit the application’s UI and UX in a future iteration. The current desktop layout leaves a large amount of unused space, while the Todo creation form receives more visual attention than the Todo list itself.
