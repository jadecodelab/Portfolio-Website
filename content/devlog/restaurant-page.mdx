I built Jade's Kitchen as part of The Odin Project's Restaurant Page assignment.

This project main goal is configuring Webpack and using JavaScript modules to generate a webpage dynamically. I created separate modules for the Home, Menu, and About tabs, then used event listeners to switch between them without reloading the page.

I learned how to:

- Configure Webpack for HTML, CSS, and images
- Create and append elements using JavaScript
- Organize code into reusable functions and modules
- Deploy a Webpack project with GitHub Pages

One challenge was understanding the DOM hierarchy. I encountered an error after trying to append an element to itself, which helped me better understand parent and child elements.
